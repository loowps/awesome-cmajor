# Contribution Guidelines

Thanks for helping to build this list. Please keep the bar high — an awesome list is valuable only in proportion to what it leaves out.

## What belongs here

- Resources that a working Cmajor developer would genuinely benefit from: documentation, tools, non-trivial patches, libraries, integrations, talks and articles.
- Community patches with something to teach — an interesting algorithm, a good project layout, a clean GUI integration.

## What does not

- Generic audio DSP resources with no Cmajor connection. Those belong in [Awesome Audio DSP](https://github.com/BillyDM/Awesome-Audio-DSP).
- Paid products or courses, unless there is a substantial free component.

## Self-promotion

Submitting your own project is fine and welcome. Hold it to the same standard you would hold anyone else's, and be prepared for it to be declined if it is early-stage.

## Removals

If a listed resource is dead, abandoned or superseded, open an issue or a pull request removing it. Keeping the list current matters as much as growing it.
